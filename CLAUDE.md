## Overview

This project implements a 2D side scrolling game in Python. It will have a starting menu screen 
and five levels. The objective is to get to the end of the final level.

There will be different enemies, some stationary and some mobile. The play will be able to collect power ups to improve their ship

## Technologies used

- Python
- PyGlEt
- Arcade
